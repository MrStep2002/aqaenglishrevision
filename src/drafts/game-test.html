Game Test

Which sentence is wrong. Ten questions, and it picks the options from the spreadsheet at random - shuffling columns each time. This isn't good for multiple choice questions where there are specific answers. It's just anything from A is correct, shuffled with anything from B or C which are both incorrect.

This one will keep rows connected so that it will only offer A1 with B1 and C1 so will work better with multiple choice questions. 

This one lets you pick words from the left column and match them with the words on the right hand side.

Organise the words so that the quotes are correct. Double click to insert in the next avaialble space or drag them down.
